# .vibe Directory - AI Council Project

This directory contains Vibe-specific configuration and workflow tools for the AI Council project.

## Files

### 📖 `rules.md`
Comprehensive project rules, coding standards, and workflow guidelines.
**Usage:** Read at start of each session

### 🚀 `start_session.sh`
Session initialization script that checks status and reminds of key rules.
**Usage:** `.vibe/skills/automation_skill/scripts/start_session.sh`

### 📝 `vibe_commands.md`
Common Vibe commands and usage patterns for this project.
**Usage:** Reference when needing command examples

### 📊 `MARKDOWNLINT_GUIDE.md`
Comprehensive markdown linting guide and best practices.
**Usage:** Reference for linting rules and fixes

### 🎯 `roadmap.md`
Project-specific roadmap and milestone tracking.
**Usage:** Update as project progresses

### ⚙️ `config.json`
Vibe configuration preferences for this project.
**Usage:** Customize Vibe behavior

### 🔄 `session_log.md`
Log of development sessions and key decisions.
**Usage:** Track progress over time

## Workflow

### Starting a Session
1. Run `start_session.sh` to initialize
2. Review `rules.md` for guidelines
3. Check `roadmap.md` for current priorities
4. Update `session_log.md` with today's focus

### Ending a Session
1. Update `session_log.md` with accomplishments
2. Commit changes with clear message
3. Note any blocking issues in `roadmap.md`

## Customization

Edit `config.json` to customize Vibe's behavior for this project:
- Preferred tools and settings
- Project-specific aliases
- Custom command patterns

## Best Practices

- Keep `rules.md` updated as project evolves
- Log significant decisions in `session_log.md`
- Update `roadmap.md` when priorities change
- Use consistent formatting across all files
